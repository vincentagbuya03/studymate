# StudyMate Brand Character Prompts

This document defines a more realistic and premium character direction for StudyMate.
The goal is to replace the earlier flat mascot feel with a believable brand assistant
that can work across onboarding, splash art, empty states, and future AI assistant UI.

## Recommended Direction

Use `Concept 1: Isko Prime` as the main brand character.

Why:
- Feels aspirational and grounded
- Matches an academic productivity app better than a cartoon mascot
- Can scale from hero art to assistant avatar
- Keeps the "Isko" identity while making it visually premium

---

## Concept 1: Isko Prime

### Role
Main StudyMate assistant and flagship brand character.

### Character Summary
A realistic Filipino university student in a clean, modern academic look. He feels
smart, calm, dependable, and quietly inspiring. He should look like someone who
actually helps students stay organized, not a cartoon sidekick.

### Visual Notes
- Male, age 19 to 22
- Filipino features
- Slim to average build
- Neat dark hair, expressive but clean silhouette
- Intelligent, approachable face
- Modern blue campus jacket or overshirt
- White inner shirt
- Minimal gold accent details
- Holding a tablet, planner, or notebook
- Optional subtle holographic academic UI floating beside him

### Primary Prompt
Use case: logo-brand
Asset type: onboarding hero character for a student productivity app
Primary request: create a premium realistic Filipino student assistant character for an academic app called StudyMate
Subject: one young adult Filipino university student, calm, confident, intelligent, supportive, approachable
Style/medium: high-end semi-realistic digital illustration, polished editorial character art, premium app branding quality
Composition/framing: three-quarter standing pose, centered, full body or upper three-quarter body, clean silhouette, designed for mobile onboarding
Lighting/mood: soft cinematic lighting, uplifting, intelligent, modern
Color palette: royal blue, white, subtle gold, soft aqua highlights
Materials/textures: realistic fabric folds, clean matte clothing, subtle screen glow from tablet
Text (verbatim): none
Constraints: must feel human, elegant, believable, refined, and aspirational; should look like a real academic guide for students
Avoid: childish mascot energy, chibi proportions, cheap flat vector style, exaggerated anime look, distorted hands, uncanny smile, generic robot assistant tropes

### Short Prompt
Create a premium semi-realistic Filipino student assistant for StudyMate, a student productivity app. He is a calm, intelligent young university student in a modern blue academic outfit with a tablet or planner, soft cinematic lighting, refined editorial illustration quality, believable human features, and a clean mobile-app-friendly silhouette. Avoid cartoon mascot style.

- Filipino features
- Professional but youthful styling
- Long or shoulder-length dark hair
- Smart casual academic outfit in StudyMate colors
- Clean planner, tablet, or notebook prop
- Gentle confident smile

## Expression Set

Once the main character is chosen, create these matching expressions:
- Neutral welcome
- Encouraging smile
- Thinking or planning
- Celebration or success
- Gentle reminder or focus mode

Prompt add-on:
Create the same character identity with consistent face, hair, outfit, and colors, but change only the expression and pose for a UI sticker or assistant state.

---

## UI Use Cases

- Onboarding hero art
- Empty state guidance
- Success state celebration
- Reminder assistant card
- Profile or assistant avatar
- Splash screen illustration

---

## Art Direction Rules

- Keep proportions realistic
- Prioritize face quality and hands
- Avoid over-rendered fantasy styling
- Use clean readable silhouettes for small-screen use
- Keep the outfit consistent across variants
- Make the character feel premium, human, and helpful
- Avoid anything that looks childish, flat, or mascot-like

---

## Recommendation Summary

If you want the strongest single StudyMate identity, use:

`Isko Prime`

If you want a softer premium brand direction, use:

`Aira Scholar`

If you want the most flexible and inclusive identity, use:

`Sage Neutral`
